# Changes from 2026-10-13 to 2026-10-15

## Scope and evidence standard

This report adds the changes made after the [2026-10-13 update](updates-2026-10-13.md), up to the evening of
2026-10-15. Where this report and an older report differ, this report wins.

Sources were reviewed privately: live service state, the bot's commit history, and the user's own requests in agent
conversations. Raw conversations are not published.

Status labels: **Live (2026-10-15)** = checked on that date; **Recorded** = written in task records, not re-checked.

Server, channel and account identifiers, tokens and network addresses are not published.

## 1. Discord bot: user-experience decisions (rig)

The bot's full decision list lives in its own repository (`docs/UX-DECISIONS.md`). Summary (Live):

- **Only full answers notify.** All status posts are silent. Three alerts stay loud on purpose: approval requests,
  failed voice transcription, and tab/channel warnings.
- **Queue message.** One silent queue message per channel, always kept as the newest message (reprinted 1.2 s after
  new messages, at most 3 s). It lists the running job (animated spinning gear, no label) and the waiting jobs.
  Every row is a jump link to the message that holds its Stop or Cancel button. A `🏁 Finished` section lists
  recent results. No buttons on the queue message itself.
- **Per-message notes.** Each waiting message gets a silent `⏳ Queued.` note with Cancel. When its job starts, the
  note is edited in place into `Working… ❌ Stop`, so the channel reads in send order.
- **Heartbeat.** The Working… message updates every 10 s (alive / quiet / stuck, running tool, CPU). When a run
  writes nothing for 8 s it shows `🗜️ Compacting memory (usually ~60 s)`; three measured compactions took 58–61 s.
- **Voice.** A voice message is replaced by its transcript right after transcription. Spoken replies arrive as one
  message with text and audio.
- **Restarts.** The bot only restarts when idle (no running or queued job, no reply being posted, no pending queue
  reprint, owner not in voice). The queue message shows `Restart pending: N updates ready`, and after the restart
  that line becomes `Restarted: running <commit>`. Restart notices are framed with a rule and an underlined header.

## 4. Disk cleanup on the rig

Free space on the rig's root disk went from **16 GB (95 % used) to 90 GB (70 % used)** (Live). Removed:

- Local AI models and their GPU environments that were no longer used, including an unused local development chat
  model (its install records were kept so it can be rebuilt).
- Old OMP versions and old private Shift-selection builds. The DarkFactory Claude gateway was moved from a pinned
  old OMP to the current one before the old version was removed (backup of its start script kept).
- A stale archive copy of the projects folder: repositories were deleted only when their content was found on
  GitHub or in the live copy. **Limit:** 12 repositories whose GitHub remotes were gone were deleted on the basis of
  stale remote records plus an existing live copy; repositories nested inside other repositories were not compared.
- Duplicate emulator ROM copies (byte-identical copies kept elsewhere), package caches, and dependency folders in
  projects unchanged for two weeks or more.
- Podcast and YouTube caption transcripts were moved into the knowledge-base repository before their working
  folders were deleted.

Lesson: on this btrfs disk, folder sizes from `du` overstate what a delete frees; report the change in `df` free
space instead. (The cause, shared blocks or concurrent writes, was not measured.)
