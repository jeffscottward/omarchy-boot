## 5. Mac reinstall on Omarchy Apple Silicon

The Omarchy Mac build on the MacBook (4.0.4-mac.1, Asahi kernel) is no longer supported. The owner will reinstall
with the Omarchy Apple Silicon edition (owner decision 2026-11-20). Before the reinstall, a separate job copied
the Mac settings to a private folder on the rig (Recorded 2026-11-20: about 800 MB, about 2,700 files, folder
mode 0700). The backup holds settings and customizations only: no work data, no browser profiles, no private
keys and no sign-in data. It also holds an inventory of packages, user and system units, tool lists and changed
`/etc` files.

### What the new edition replaces

- The community Mac build, its kernel and its package set. Do not copy packages or binaries from the old
  install. Install missing packages again for aarch64; the new edition may already include Asahi audio,
  keyrings and the shell components.
- The Omarchy default files. Do not copy old default files over new ones; compare and apply personal changes
  on top.
- System files that the installer makes: `fstab`, `passwd`, `group`, `subuid`/`subgid`, `resolv.conf`, the GRUB
  defaults, `pam.d` and `skel`. Do not copy these back.

### Restore order

1. Finish the stock install and update the system.
2. Sign in to 1Password and Tailscale by hand. Check that the node keeps the `omarchy-mac` name.
3. SSH: make a new client key (or restore it from 1Password), copy the SSH aliases and known host keys from the
   backup, and add the new public key on the rig. The rig sees a new host key for the Mac.
4. Packages: compare the inventory lists with the new system and install only what is missing.
5. Settings: copy each folder from the backup and compare before you overwrite: Hyprland (`hypr/*.lua`:
   bindings, input and trackpad, monitors, look and feel, autostart), Omarchy plugins and menu overrides,
   Herdr, terminals, Neovim, fcitx5, custom `.desktop` entries, personal scripts in `~/.local/bin`, shell setup
   and the OMP agent rule files and lessons. Skip old `.bak` and `.before-*` files.
6. System files: restore the keyd rule for the Fn dictation key, the Apple keyboard module option, the sysctl
   files (including MPTCP off) and the udev rules. Compare the firewall, `pacman.conf`, locale, Plymouth,
   resolver and snapshot settings by hand.
7. Developer tools: install them again with mise (OMP, Node, Bun, GitHub CLI and others in the inventory).
8. Private builds, rebuilt natively on aarch64 and never copied: the private OMP Shift-selection build (see
   the [2026-10-08 update](updates-2026-10-08.md)), the patched Wispr Flow runtime and native helper, and FEX
   only if still needed. Reinstall the Heeler Herdr plugin and pair the phone again.
9. User services: copy the unit files, then enable the units listed in the inventory (streaming, Bluetooth,
   AirPods support, theme sync, lid and sleep lock, monitor recovery, input method, Tailscale file receive and
   others).
10. Sign in again: GitHub and GitLab CLIs, OMP model accounts (never copy the OMP database), provider API keys
    from 1Password, Wispr Flow, Chrome sync. Pair Moonlight again.
11. Checks: dictation with lists and newlines, Fn key dictation, trackpad gestures and tap-to-click, theme sync
    to the rig, SSH to the rig, OMP starts with the private build, Herdr opens, audio and brightness keys, lid
    lock and sleep.

### What is not restored

- Retired tools: Punktfunk, Karabiner, Hammerspoon, stop-stutter and the old remote-desktop stack.
- Caches, browser profiles, Steam data and work data (work data lives on the rig).
- Private keys, API keys, sign-in tokens and the OMP database. An encrypted key archive was not made; it needs
  an owner decision.
- The old sudo rules: the backup could not read them. Their content is unknown.
