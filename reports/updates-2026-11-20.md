## Scope and evidence standard

This report adds the changes made after the [2026-10-18 update](updates-2026-10-18.md), up to 2026-11-20. Where
this report and an older report differ, this report wins. Section 6 lists the older statements that this report
replaces.

Sources were reviewed privately and read-only: the package manager log on both Omarchy hosts, the Hyprland and
Omarchy configuration folders, `/etc/sysctl.d`, installed tool versions and the agent rule files. Raw logs and
conversations are not published.

Status labels: **Live (2026-11-20)** = checked on that date; **Recorded** = written in rule files or task records,
not re-checked for this report.

Server, channel, message and account identifiers, tokens, network addresses and host names are not published.
Trading details are not published.

## 5. Mac reinstall on Omarchy Apple Silicon

The Omarchy Mac build on the MacBook (4.0.4-mac.1) is no longer supported. The owner will reinstall with the
Omarchy Apple Silicon edition (owner decision 2026-11-20). A separate job backs up the Mac settings to the rig
before the reinstall; work data stays on the rig and is not part of that backup.

### What the new edition replaces

- The community Mac build, its kernel and its package set. Do not copy packages or binaries from the old
  install; install them again for aarch64 from the new edition.
- The default Hyprland Lua files: use the files of the new edition and apply personal changes on top of
  them; do not copy the old files over them.

### Restore order

1. Install the Omarchy Apple Silicon edition and run its first-start steps.
2. Restore SSH client keys and aliases from the backup; check host keys again (the Mac gets a new host key).
3. Install OMP and Herdr at the versions in use on the rig; restore the OMP agent rule files and lessons.
4. Restore personal desktop settings (bindings, look and feel, autostart, theme hook) by applying them to the
   new Lua files.
5. Install the Omarchy plugins listed in section 2 from their sources.
6. Rebuild the private Wispr Flow runtime and the private OMP Shift-selection build natively on the new install (see
   the [2026-10-08 update](updates-2026-10-08.md)); never copy them from the old install.
7. Sign in to apps (1Password, browser, Wispr Flow) by hand. Sign-in data is not restored from the backup.
8. Check theme sync from the Mac to the rig, notifications and the SSH routes in both directions.

### What is not restored

- Retired tools: Punktfunk, Karabiner, Hammerspoon and the old remote-input stack.
- The community Mac build workarounds for 16 KiB memory pages (FEX update aborts) unless the new edition needs
  them again.
- Caches, browser profiles, Steam data and work data (work data lives on the rig).
- Credentials and sign-in tokens.
